# ☕ CoffeeStore Bot

Асинхронный Telegram бот для автоматизации учёта товаров, финансовых операций и аналитики для бизнеса по продаже товаров для кофемашин.

## 🎯 Основные возможности
### ✨ Решаемые проблемы

- ❌ Ручной учёт в Excel с формулами
- ❌ Смешение логики расчётов и данных
- ❌ "Магические числа" в формулах (курсы, коэффициенты)
- ❌ Сложность отслеживания остатков и прибыли
- ❌ Высокая вероятность человеческих ошибок

### ✅ Преимущества

- ✅ Автоматизация операций учёта
- ✅ Устранение ошибок расчётов
- ✅ Упрощение процесса продаж
- ✅ Получение аналитики в реальном времени
- ✅ Удобный интерфейс Telegram
- ✅ Асинхронная обработка запросов

## 🏗️ Архитектура

- **Backend:** PostgreSQL + SQLAlchemy (Async)
- **Frontend:** Telegram Bot (aiogram 3.x)
- **Миграции:** Alembic
- **Язык:** Python 3.11+

## 🚀 Быстрый старт

Подробная инструкция по установке и настройке находится в [INSTALLATION.md](INSTALLATION.md)

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd coffeestore_bot

# 2. Установить зависимости
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate  # Windows
pip install -r requirements.txt

# 3. Настроить .env файл
cp env.example .env
# Отредактируйте .env файл (см. ENV_SETUP.md)

# 4. Применить миграции
alembic upgrade head

# 5. Запустить бота
python main.py
```

## 📈 Бизнес-логика

### Расчёт себестоимости

```
Себестоимость = (Цена закупки в CNY × Курс CNY→SOM) + (Вес × Стоимость доставки за кг)
```

### Расчёт прибыли

```
Прибыль = (Цена продажи × Количество) - (Себестоимость × Количество)
```

### Управление остатками

```
Текущий остаток = SUM(Приход из доставленных заказов) - SUM(Расход из продаж)
```
